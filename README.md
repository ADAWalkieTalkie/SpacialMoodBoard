**Glide Through Layers, Glayer**

3D 공간 속에 이미지를 배치하고, 사운드로 감정을 더하세요. 영화처럼 공간을 연출하는 새로운 무드보드, *Glayer*


Glayer는 이미지를 3D 공간에 자유롭게 배치하고, 사운드를 더해 영화의 무드를 구성하는 감각적 창작 툴입니다.
당신만의 세계를 한 장면처럼 구성하고, 몰입형으로 감상해보세요!

주요 기능
- 2D 이미지 불러오기 및 누끼 제거 지원
- 이미지 레이어링으로 깊이감 있는 공간 구성
- 배경음과 효과음으로 무드 디자인
- Full Immersive View로 완성된 공간 체험
- 완성된 공간 무드보드에 직접 들어가 감상

Glayer는 단순한 편집 도구가 아닌,
당신의 감정과 상상을 공간으로 표현하는 새로운 시네마틱 플랫폼입니다.

<br> 

## About Glayer
#### Team WalkieTalkie
#### Problem
> 서비스 소개: <br/>
영화 미술감독은 무드보드를 만들어가며, 감독에게 ‘이렇게 만들면 될까요?’ 하고 컨펌을 받으러 갑니다. <br/>
문제는 이때 발생하게 됩니다. <br/>
<u>*무드보드: 영화의 분위기를 한 곳에 모은 이미지 모음집</u>
<br/>
> 감독의 머릿속 이미지와 미술감독이 만든 무드보드가 달라 <br/>
>“이런 느낌이 아닌데…?”라는 피드백이 계속 반복됩니다. <br/>
><br/>
>감독은 공간을 실제로 보기 전까지 상상이 잘 안 되고, <br/>
>미술감독은 그 간극을 줄이기 위해 계속 보완해야 하죠. <br/>
><br/>
>이렇게 끊임없이 최종, 최최종, 진짜 최종 버전의 무드보드를 만들면서 <br/>
>정말 많은 시간과 에너지를 쏟게 됩니다. <br/>
>하지만 이 과정은 영화 제작에 있어 필수적이기 때문에 피할 수는 없는데요 <br/>

#### Solve
>그래서 저희는 영화 미술감독에게 반복되는 피드백을 줄일 수 있는 <br/>
>새로운 워크플로우 *Glayer*를 제안합니다.

<br>

## 🪼 **Target User**
*Primary Target*

**🎬미술감독**
- 감독에게 공간 톤, 무드, 감정적 분위기를 더 정확하게 전달해야 하는 사람들
- 공간디자인, 소품 등 영화 속 비주얼적인 요소를 채워나가야 하는 사람들
- Scene·Set 분위기를 빠르게 시각적·공간적으로 구성해야 하는 팀

*Secondary Target*

**🍿연출팀**
- 무드보드 기반 피드백 시간 단축하면 좋은 사람들
- 감각적 톤을 공간적으로 즉시 이해할 필요가 있는 역할
